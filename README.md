# 🏨 Hotel Booking Management System

A full-stack Hotel Booking Management System built using **PHP, MySQL, JavaScript, and Bootstrap**.
This project simulates a real-world hotel booking platform with user and admin functionalities.


## 🚀 Features

### 👤 User Side

* View available rooms without login
* Room details with images, price, and description
* User registration & login system
* Book rooms with:

  * Check-in / Check-out dates
  * Adults & Children selection
  * Mobile number
* Real-time room availability check (prevents double booking)
* 💳 Payment options:

  * Cash on check-in
  * Online payment (Razorpay)
* 🎁 Coupon system for discounts
* ⭐ Ratings & Reviews system
* 📖 My Bookings page


### 👨‍💼 Admin Panel

* Secure admin login
* Add / Edit / Delete rooms
* Upload room images
* Manage room availability (Available / Not Available)
* View all bookings with user details
* Track payment status (Paid / Cash)


### 📊 Analytics Dashboard

* Total bookings count
* Total revenue
* Most booked room
* Top-rated room
* Monthly revenue insights


## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, Bootstrap, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Payment Gateway:** Razorpay



## 🗂️ Database Tables

* `users`
* `rooms`
* `room_types`
* `bookings`
* `payments`
* `ratings`
* `coupons`



## 🔐 Authentication

* Session-based login system
* Role-based access:

  * User
  * Admin



## 💡 Key Functionalities
